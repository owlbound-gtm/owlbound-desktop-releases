# Owlbound for Mac

Downloads for the Owlbound desktop app: live meeting transcripts and notes, saved to your Owlbound workspace. No meeting bot; audio is never stored.

Get the latest version from the [Releases](https://github.com/owlbound-gtm/owlbound-desktop-releases/releases/latest) page or from the Context page in Owlbound.

This repository only hosts release builds. The source code is private.
